# Accessibility Statement

People may use accessibility statements as a reference when they have trouble using a website. We’re committed to updating this statement as needed to:

- Remove resolved issues.
- Add new issues that arise.
- Include potential workarounds.

For questions, [contact us](/contact-us).

## GC Platform is maintained by the Government of Canada

The [Canadian Digital Service](https://digital.canada.ca/) (CDS) operates GC Platform. CDS is part of [Employment and Social Development Canada](https://www.canada.ca/en/employment-social-development.html) (ESDC). We must comply with the [Treasury Board Standard on Web Accessibility](https://www.tbs-sct.canada.ca/pol/doc-eng.aspx?id=23601).

GC Platform is based on open-source code from Zitadel. CDS modified both code and content for the Government of Canada context.

### This statement reflects the accessibility of the GC Platform website, not other CDS Platform products

We design, develop and maintain GC Platform for use by public servants.

Our tests include screen sizes equivalent to desktop and mobile devices. 

### We’re working to comply with the [Web Content Accessibility Guidelines](https://www.w3.org/TR/WCAG21/#sotd) (WCAG)

We aim for accessibility in design and development of both new and existing features. We address accessibility issues on an ongoing basis.

Our tests include:
- Automated tests via Playwright on our front-end website and static pages. 
- Manual tests to catch issues missed by automated tests.
- Design research to learn how we can improve accessibility on  GC Platform.

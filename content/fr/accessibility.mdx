# Déclaration d’accessibilité

Il se peut que les gens utilisent les déclarations d’accessibilité comme référence lorsqu’ils ont des difficultés à utiliser un site Web. Nous nous engageons à mettre à jour cette déclaration au besoin afin d’y apporter les modifications suivantes :
- supprimer les problèmes résolus;
- ajouter les nouveaux problèmes qui se posent;
- inclure des solutions de rechange.

Pour toute question, [contactez-nous](/contact-us).

## Plateforme GC est un outil entretenu par le gouvernement du Canada 

Le [Service numérique canadien](https://numerique.canada.ca/)(SNC) assure l’exploitation de Plateforme GC. Le SNC fait partie d’[Emploi et Développement social Canada](https://www.canada.ca/fr/emploi-developpement-social.html) (EDSC). Nous devons nous conformer à la [Norme du Conseil du Trésor sur l’accessibilité des Sites Web](https://www.tbs-sct.canada.ca/pol/doc-fra.aspx?id=23601).

Plateforme GC est basée sur le code source libre de Zitadel. Le SNC a modifié le code et le contenu pour les adapter au contexte du gouvernement du Canada.

### Cette déclaration reflète l’accessibilité du site Web de Plateforme GC, et non des autres produits de la Plateforme du SNC

Nous concevons, développons et entretenons l’outil Plateforme GC en vue de son utilisation par les fonctionnaires.

Nos tests incluent des tailles d’écran équivalentes à ceux des appareils de bureau et des appareils mobiles. 

### Nous nous efforçons de respecter les [Règles pour l’accessibilité des contenus Web](https://www.w3.org/TR/WCAG21/%23sotd) (WCAG)

Nous visons une conception et un développement accessibles, aussi bien pour les nouvelles fonctionnalités que pour les fonctionnalités existantes. Nous traitons continuellement les problèmes d’accessibilité.

Nos tests comprennent :
- des tests automatisés réalisés à l’aide de Playwright sur notre site Web frontal et sur les pages statiques; 
- des tests manuels visant à déceler des problèmes que les automatisations ont manqués;
- des recherches en matière de design pour découvrir comment nous pouvons améliorer l’accessibilité sur Plateforme GC.

# Autres services utilisés par Plateforme GC
Nous utilisons des technologies et des services d’autres organismes.

Il est possible que durant l’utilisation de ces technologies et services, nous communiquions des renseignements personnels avec :

- [Amazon Web Services](https://aws.amazon.com/)
- Le capteur d’informatique en nuage du [Centre canadien pour la cybersécurité](https://cyber.gc.ca/fr)
- [Freshdesk](https://freshdesk.com/)
- [Slack](https://slack.com/)
- [Zitadel](https://zitadel.com/docs)

Nous utilisons également les services suivants :

- [Google Analytics](https://analytics.google.com/analytics/web/provision/%23/provision)

- [Salesforce](https://www.salesforce.com/ca/)
